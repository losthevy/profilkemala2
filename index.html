PEATGUARDModel 3D node prototipe · ESP32-S3 + SX1262
Cara pakai
  • Seret untuk memutar, gulir atau cubit untuk zoom, klik kanan + seret untuk menggeser.
  • Arahkan kursor ke bagian alat untuk melihat namanya, lalu klik untuk detail.
  • Saat sebuah bagian dipilih, bagian lain dipudarkan. Klik area kosong atau tekan Esc untuk kembali.
  • ← / → berpindah ke komponen sebelumnya/berikutnya.
  • Mode foto menyembunyikan semua panel untuk tangkapan layar.
